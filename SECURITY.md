# Security Policy

No reportes credenciales ni datos sensibles en issues públicos. Para informar
una vulnerabilidad, contacta al mantenedor mediante el perfil de
[Mauricio Perera](https://github.com/MauricioPerera) y proporciona únicamente
los detalles mínimos para reproducirla.

Los adapters deben conservar tokens en el host, aplicar allowlists y limitar
tiempo y salida. No aceptamos secretos dentro del repositorio.
